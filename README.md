# what-to-AI

한국어 개발 지침서. 일반 개발 원칙, 기획, 코드 작성, 테스트, 배포, AI 협업, 프롬프트 템플릿을 제공합니다.

## 실행

Node.js 20 이상에서 `npm run dev`를 실행하고 http://127.0.0.1:3000 을 엽니다. 외부 npm 의존성은 없습니다.

`npm run build`는 배포할 정적 파일을 `dist`에 복사합니다.

## Vercel 배포

이 폴더를 Vercel 프로젝트의 Root Directory로 지정합니다. 상위 저장소를 연결했다면 `what-to-AI`를 선택합니다. Framework Preset은 Other이며 `vercel.json`에 빌드 명령과 출력 경로가 설정되어 있습니다. 환경 변수나 데이터베이스는 필요하지 않습니다.

CLI를 사용하는 경우 이 폴더에서 `vercel`로 미리보기 배포를 하고, 확인 후 `vercel --prod`로 배포할 수 있습니다.

## 문서 수정

`app.js`의 `guides` 배열에서 문서 제목, 설명, 분류, 본문을 수정합니다. 문서 주소는 `#planning` 같은 해시를 사용해 새로고침과 직접 링크를 지원합니다. 검색은 본문을 포함하며 분류 필터와 함께 사용할 수 있습니다. 지침 복사는 HTTPS 또는 localhost에서 지원됩니다.

외부 Google Fonts가 로드되지 않아도 시스템 글꼴로 표시됩니다. 로그인, 서버 저장, 문서 편집 기능은 포함하지 않습니다.

## 프로젝트 지침 생성과 요청 템플릿

- `#builder`: 프로젝트 이름, 기술 스택, 언어, 패키지 관리자, 적용 원칙, 코드 규칙, 검증 방식, 제약 조건으로 Markdown 지침을 조합합니다.
- `#templates`: 기능 추가, 버그 수정, 리팩터링, 코드 리뷰, 배포 점검용 요청을 작성합니다. 각 유형의 입력은 화면을 오가도 탭 내에서 유지됩니다.
- 두 화면 모두 실시간 미리보기, 복사, `.md` 다운로드를 제공합니다. 입력은 서버나 외부 AI로 전송하지 않으며 새로고침하면 초기화됩니다.
- 생성 규칙과 템플릿 내용은 `tools.js`에서 수정합니다. 실제 AI API 호출은 사용하지 않습니다.
